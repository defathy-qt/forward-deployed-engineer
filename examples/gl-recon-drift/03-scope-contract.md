# 范围合同 — GL 对账·调账预审 / Iris Bank / v1

> 阶段 S2 · 模块 02-scoping。**工件 ID：SCP-iris-v1**（2026-08-06 双方签字 = 范围冻结）
> 本件作为 **poe 场景三边界** 的外部证据；与 STM-iris-01、DSC-iris-20260804-01 配套。

## 1. 做（In scope）

- 跨 6 系统的账务对账差异归因（总账/子账/资金/计提 × ESB × 文件交换平台）
- 「归因 + 调账建议草稿」输出（含**依据引用**：当日映射快照、原始凭证号、文件批号）
- 科目映射漂移检测（对照盘读取 subject_mapping 快照差异 → 预警）
- RO 交互：接单/拒绝并说明/接管升级；授权门二段式（经办拟+授权复核）
- 归因类指标看板 + 审计事件查询（调账草稿 full 链）

## 2. 暂不做（Deferred / later）

- 自动过账 / 自动调账（**根本不做**，见 §3）
- 账实项（库存/存在性盘点）之外的跨库数据质量清洗
- 移动端 / 对监管报送的自动填单
- 多银行集团版（本套先服务 Iris 本体）

## 3. 绝不自动承诺（Never auto-commit）——红线

| 动作 | 为什么 | 谁来执行 |
|---|---|---|
| **过账 / 调账**（借贷方向、金额落地） | 不可逆、影响报表与监管 | 永远人工：经办录入 + 授权人复核双签 |
| **修改科目映射表** | 权威性/单一事实源 | 永远人工授权门；系统只读授信 |
| **摸客户名/户余额外提** | 数据边界与隐私 | 系统不提供批量外提能力 |
| 系统**自动报送监管** | 合规责任在机构 | 人工发起，系统不触发 |

> 红线进 **runbook** 成为强制校验（见 08-runbook-excerpt.md）。

## 4. 围栏动作（Fenced actions，试点期即生效）

- 建议草稿的**自动回填**：L2 范围仅限"归因理由自动起草 + 依据引用"，**不触碰提交/过账**
- 自动比对引擎：只读镜像内联运行，**永不写回生产总账**
- 预警外发：漂移/文件缺失 → 告警只有通知语义，不含账务动作

## 5. 数值化停止条件（硬，不赌"差不多"）

| 条件 | 值 | 触发者 |
|---|---|---|
| 归因正确率（golden） | < 85%（结果层） | 评测停工 |
| 依据层引用可回溯率 | < 95% 或任何未授权"外部知识拼接"令 | 停工并回溯 |
| 越权/不安全建议 | **任意 1 例** → 熔断 | 立即冻结并升级 |
| 单一差异定位时长 P95 | > 15 分钟 | 重开定位流程 |
| 放权 L2 越界动作 | 任意 1 例 | 冻结 L2，退回 L1 |

## 6. 升级路径

- **P0 不安全**：值班冻结 → 会计室主任知情（15 分钟内）
- **P1 报告-级事故**：对应 ISS 模板；根因→修正→回归入 golden set
- **范围蔓延**：任何"顺带自动报送/自动调账"需求 → 引用本合同 §2/§3 拒绝或走新合同

## 7. 已确认（签字摘要）

- 会计室主任（决策人）与 RAC01 对账专项工单一致；审计部认可审计事件的"最小必需集合"口径。
- 基线（3 天 / 40 min / 11%）锁定为验收参照，不随开发漂移。
- 双 Owner：会计室主任（业务）+ 科技部运维（技术）；值班具名到人。
- 例外豁免：8 月月结窗口（2026-08-26 起）为**险情窗口**，门禁期运行 L0/L1。
