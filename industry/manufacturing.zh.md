# 行业画像：制造业（离散/流程制造）

> 用法：discovery 阶段对照本画像快速建立行业语境；它是行业约束层，不替代现场调研。
> 关键术语保留英文以便与系统/文档对齐。

## 1. 业务对象与核心流程

| 对象 | 说明 | FDE 常见切入点 |
|---|---|---|
| 物料/BOM | 物料主数据、多级 BOM、工程变更（ECN） | 主数据问答、变更影响分析 |
| 工单/排产 | 生产工单、工序、排程、齐套 | 异常工单分诊、齐套检查助手 |
| 仓储/物流 | 入库、库位、拣配、发运、盘点 | 库存差异解释、单据核验 |
| 质量 | 来料/过程/成品检验、不合格品、8D | 质检报告生成、标准问答 |
| 设备 | 设备台账、点检、维保、OEE | 维保知识助手、故障记录结构化 |
| 采购/供应商 | 采购订单、交期、对账、绩效 | 交期异常升级、对账辅助 |

## 2. 典型系统地形

- ERP：SAP ECC/S4、用友 U9/NC、金蝶、Oracle EBS（常多套并存、历史定制重）
- MES：西门子 Opcenter、宝信、石化盈科、自研车间系统（车间侧数据实时性强）
- WMS：曼哈特、富勒、自研；APS 排产；QMS；设备 IoT/SCADA/Historian
- 集成现实：IDoc、SOAP、ODBC、文件摆渡、OPC-UA、Kafka 混用；车间与办公网常物理隔离

## 3. 高频 FDE 场景与价值基线

| 场景 | 典型基线（现场重测） | 结果指标 |
|---|---|---|
| 异常工单分诊 | 跨 5–8 系统查单，平均 30–40 分钟 | 处理时长、一次解决率 |
| 质检/体系标准问答 | 质量员翻 SOP/体系文件，答复不一致 | 无纠正率、引用可溯率 |
| 供应商交期协同 | 邮件/电话追单，升级滞后 | 准时交付率、升级及时率 |
| 维保知识助手 | 老师傅经验在个人脑中 | 故障定位时长、新人上手周期 |

## 4. 合规与安全要点

- 工艺参数、配方、BOM、供应商价格属商业秘密；默认数据不出厂
- 工控网/办公网隔离（等保 2.0 三级常见）；任何写入 MES/SCADA 必须围栏
- 质量与安全记录有留存与追溯要求（审计事件不可篡改）
- 动作风险高：排产、投料、放行、采购承诺类动作默认 L1 辅助、人工执行

## 5. 推荐模块组合

01-discovery → 03-integration-architecture（重点 IDoc/文件摆渡/OPC-UA 连接器）
→ 04-evaluation（Golden Set 必含历史质量事故与工艺边界案例）→ 05-pilot-adoption
（按车间/班次设围栏，种子用户选班组长）→ 06-deployment-runbook（气隙见 10-airgap-deploy）
→ 09-retro-assets（BOM/工单/质检类 Skill 与连接器最易跨厂复用）

## 6. 典型陷阱（现场高频）

1. 把"领导要的看板"当问题，真问题在车间跨系统查单等待
2. 主数据一物多码/命名不统一，检索召回看似模型问题实为数据问题（先定位故障层）
3. 直接回写 MES/ERP，缺动作围栏与审批；应长期保持人在环上
4. 用办公网方案设计车间网络，忽略工控隔离与网闸延迟
5. 试点选最复杂产线；应选数据齐、Owner 强、流程稳的产线先跑通
6. 老师傅经验未显性化就做知识库，知识源本身不可靠
